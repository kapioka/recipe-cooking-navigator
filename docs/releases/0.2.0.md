# Recipe Cooking Navigator 0.2.0

レシピを作る・取り込む・調理する・振り返る主要フローを整え、クリーム色、セージ、深いグリーンで画面の見た目を統一したAndroid版です。

## 今回の更新

- ホームを基準に、レシピ作成、内容確認、詳細、Version履歴、評価、料理の好み、設定、調理、Kitchenを内容ごとのまとまりへ整理。
- 本と鍋の新しいアプリアイコンと、通常・adaptive launcherへの対応。
- 条件入力、作成中、内容確認の3段階。下書き保持、取消、二重生成防止、保存失敗時の再試行。
- ファイル・貼り付け・共有から取り込む場合も、内容を確認してから保存。
- 任意の料理写真の選択、位置・拡大率の調整、丸い切り抜き、変更・削除。写真はRecipe IDごとに端末内へ保存し、Version間で共通に使用。
- 切り抜き範囲を細い円周線で表示し、一覧の写真は少し内側へ収めて表示。
- 狭い画面と文字拡大時の入力欄、材料・分量、調理・タイマー操作の表示を改善。
- 一覧の人数・時間と難易度を別行にし、一覧・詳細で5つの長方形による難易度バロメーターを共通化。料理名の下の情報をまとめ、「版」は「バージョン」へ変更。
- 詳細の調理開始・再開・評価操作を材料・器具・事前準備・全体工程の後へ移動。最終工程の下部に確認付きの「調理完了」を配置し、一覧の三点メニューにも評価への導線を追加。
- ホームの「︙」に「最新版レシピに変更」を追加。すでに最新版なら無効化し、切替の保存失敗時は元のVersionを維持。過去Versionと調理途中の記録は保持（Issue #14 / PR #15）。

## 0.1.0から追加された主な機能

- Recipe / Feedback Schema v2、対応レシピの人数変更。
- 最新Versionと次回使用Versionを分けた履歴管理、調理後評価、Feedback共有、選択Versionからの改善依頼。
- Kitchenの時計・共通タイマー、料理の好みとProfile履歴の基盤。
- Sign in with ChatGPTを本体へ統合したレシピ生成と確認・保存。別のPoCアプリは不要。

## 更新とデータ

同じ署名鍵のAPKで既存アプリを上書き更新します。アンインストールやデータ消去は不要です。

現行版はSchema v2のみを受け付けます。0.1.0のv1保存領域は残しますが、自動変換や一覧への表示は行いません。v1レシピは公開ChatGPT Project Packageのv2指示で再作成して取り込んでください。

料理写真はRecipe / Feedback JSON、Drive共有、Android自動バックアップ・端末移行に含めません。写真なしでもお皿アイコンでレシピを表示します。

## 検証と残る確認

unit / widget tests、静的解析、正式署名build、公開AI v2契約との照合で検証します。幅320/412と文字倍率1/2の画面・操作条件を含みます。生成元commit、APKのSHA-256、署名証明書、最終検証結果はGitHub Releaseに記録します。

端末の写真選択・切り抜き・一覧への反映は利用者と確認しました。各画面の最終的な見た目と写真表示の微調整は利用者による確認が残っています。調理雑音下の音声認識、TalkBack、長時間点灯、Kitchenの背景動作、Profileの実運用も未確認です。SNS共有素材、ファイルによるバックアップ、iOS版は未実装です。

タイマー終了で自動的に次工程へ進むことはありません。食品安全上の注意と無保証については[DISCLAIMER](../../DISCLAIMER.md)を参照してください。
