# Recipe Cooking Navigator 0.2.1

レシピ改善の回答受信を修正し、詳細・評価画面の見た目と、バージョンごとの変更内容を確認する流れを整えたAndroid版です。公開準備中の候補で、アプリのバージョンは `0.2.1+3` です。

## 今回の更新

- 調理後の評価から送った改善の希望を次の画面に表示し、追加の希望と区別できるように変更。
- 生成依頼の説明と構造例を整理し、コンパクトなRecipe JSONの回答を依頼。材料・分量・食品安全の情報とSchemaの必須項目は維持。
- 回答本文と受信通知の上限を分離し、完成した回答を受け取った時点で内容確認へ移動。時間切れや受信上限の理由を表示し、作成条件は保持。
- レシピ詳細と調理後の評価を、一覧・調理画面と同じクリーム色、深いグリーン、文字の階層、内容ごとのカードへ整理。
- 評価画面のChatGPTへの改善依頼を濃い緑、Feedback共有を枠線のボタンへ変更。
- 改善候補と保存後の詳細で、改善元から変更・追加・削除された内容を表示。
- 今回から作成するレシピの送信条件、評価から引き継いだ改善希望、使用モデルを端末内に記録。以前のレシピに記録がない場合は、その旨を表示。
- バージョン履歴で材料・器具・準備・工程を左右スワイプで閲覧。比較元は使用中のバージョンを初期値とし、ほかの保存済みバージョンにも変更可能。
- 緑は表示中、淡い赤は比較元の内容として固定し、役割とバージョン番号を文字でも表示。閲覧だけでは使用中のバージョンや調理途中の記録は変更しない。
- バージョンをカードとして左右に動かすアニメーションを追加。短いスワイプは元の位置へ戻り、端末のアニメーション無効設定にも対応。
- 変更点を内容別の件数と短い比較行へ整理。長い全文や削除内容は個別に開いて確認し、工程の変更件数から詳しい工程を開いて移動。
- 日本語の色付けが一文字ずつ細切れにならないよう、句読点・改行などで区切った文章のまとまりを比較。数値は小数を含めて値全体を色付け。
- 画面内の「版」を「バージョン」へ統一。

## 更新とデータ

同じ署名鍵のAPKで既存アプリを上書き更新します。アンインストールやデータ消去は不要です。

Recipe / Feedback Schema v2を維持し、過去のバージョン、使用中のバージョン、調理記録を保持します。作成条件の記録はRecipe JSONとは別の端末内データで、Recipe / Feedback JSON、Android自動バックアップ・端末移行には含めません。今回の記録機能より前に保存したレシピの条件は復元できません。

## 検証と残る確認

本体のunit / widget tests 283件、静的解析、formatterが成功しています。共通SIWCの26 testsと静的解析は、回答受信の修正時に成功しています。幅320 / 412と文字倍率1 / 2、バージョン切替、比較元選択、変更内容の表示、元データの保持を含みます。

既存版と同じ証明書の正式署名APKでPixel 10aを更新し、起動とAPK checksumの一致を確認しました。改善レシピの受信は実機で成功し、利用者も生成後の保存を確認しています。応答時間はモデルや通信状況に依存し、短縮を保証しません。

最新の色付け、カードの動き、各画面の最終的な見た目は利用者による確認が残っています。調理雑音下の音声認識、TalkBack、長時間点灯、Kitchenの背景動作、Profileの実運用は未確認です。SNS共有素材、ファイルによるバックアップ、iOS版は未実装です。

配布APKの生成元commit、SHA-256、署名証明書、最終検証結果は公開時のGitHub Releaseに記録します。タイマー終了で自動的に次工程へ進むことはありません。食品安全上の注意と無保証については[DISCLAIMER](../../DISCLAIMER.md)を参照してください。
