# 2026-10-25 インストール元の取り違えと復元

## 原因

- Symptom: 0.2.4 (6)の端末更新で、アイコン・画面デザインが古くなった。
- Root cause: 端末の0.2.3を作ったソースを特定せず、古い`codex/issues-7-8-ai-integration`（HEAD `52384ba`）で実装・ビルドした。署名一致・版番号・そのソースのテスト成功を、使用中のアプリとの機能・表示の連続性を示す証拠として扱ってしまった。
- Applicability: 同じpackage・署名鍵を使い、複数のworktreeと未コミットの配布元が存在するこのリポジトリ。

## 復元元と実施内容

- 退避した端末の0.2.3 APKと、`recipe-repair-update`に残るAPKのSHA-256が完全一致した。
- 0.2.3 APK SHA-256: `ea52c6c56a4dc801ab5c5ec287db80896a7e7033b6810603824b9b8dbaf1a88a`
- 同worktreeの`fadcd8a`と31個の変更・追加ファイルを、別の`restore-current-recipe-ui`へ読み取り専用で複製した。元worktreeは変更していない。
- 修正ブランチ: `codex/restore-current-ui-and-sharing`。この作業時点でGitHubへのpush・main統合はしていない。
- 既存の評価なし再作成・アプリ内生成を再利用し、レシピ単体のコピー・共有を既存メニューへ追加した。古い画面や生成処理は移植していない。

## 確認した証拠

- Androidリソース18ファイルと`RecipeTheme`は復元元ソースと一致。
- ビルド済みAPK内のAndroidリソース14エントリは0.2.3 APKとすべて一致。ランチャーのadaptive iconも同一。
- 本体299テスト成功。追加共有テスト3件はlint修正後にも成功し、静的解析は指摘なし。
- 登録済みの同一鍵で0.2.5 (7)を正式署名し、Pixel 10aへ`adb install -r`で更新した。端末内APKと生成APKのSHA-256が一致し、起動・回転設定0/0維持・対象プロセスの致命的例外なしを確認。
- 0.2.5 APK SHA-256: `37b54d48af13320187ec5ff50dc3ec7aac33ddba52d8f32db24028723556f8e5`
- 実機上の最終的な表示確認と、実際のChatGPT往復はユーザー確認待ち。

## 次の作業に使う識別情報

この修正版のソースは`restore-current-recipe-ui`と上記ブランチ。次の更新で別のtreeを選ぶ場合は、署名や大きな版番号だけで判断せず、端末APK・配布元APK・ソースの対応を確認する。対応が確認できないソースからのインストールは繰り返さない。これは今回の再作業を避けるための復元記録であり、global policyや新しい必須ツールを追加するものではない。
